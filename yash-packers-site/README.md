# Yash Packers – concept website redesign

A static, multi-page website built from the SEO and website audit of www.yashpackersgn.in.
No build tools, no server, no database: plain HTML, one CSS file, one small JS file. Hosts on GitHub Pages for free.

## Host it on GitHub Pages (5 minutes)

1. Create a new **public** repository on GitHub (for example `yash-packers-site`).
2. Upload everything in this folder to the root of the repository (`index.html` must be at the top level, with the `assets` folder next to it).
3. Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch `main`, folder `/ (root)` → Save.
4. After one or two minutes the site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

When Yash Packers wants it on their own domain, add a file named `CNAME` containing `www.yashpackersgn.in`, point the domain's DNS at GitHub Pages, and set up 301 redirects from the old IndiaMART URLs (see the audit, section 6).

## Before showing it as "final": things to replace

Search each file for these and replace:

- **Phone number** – `+91 98XXX XXXXX`, `+919800000000` and `919800000000` (the WhatsApp number, country code first, no spaces). One verified number everywhere.
- **Email** – `sales@yashpackersgn.in` is a suggestion. Create it or replace it.
- **Preview banner** – delete the line beginning `<div id="preview-banner">` in every page (and the `#preview-banner` rule in `styles.css`).
- **Photographs** – every grey box marked "Product photograph (to be supplied)" and "Factory … photograph (to be supplied)". Replace the `<div class="photo">…</div>` with `<img src="assets/img/your-photo.webp" alt="…">`. Use the file-naming and alt-text pattern from the audit (section 10).
- **Technical figures** – density ranges, sheet sizes, MOQ, lead times, capacity, hours. The spec tables say "confirm at quotation" wherever a figure could not be verified. Publish only what the factory can stand behind.
- **ISO certificate** – `about.html` has a placeholder row. Add the certificate number and a PDF only if it is current.
- **Registered office** – `about.html` shows C-430, Pocket P3. Decide whether to publish it.
- **Canonical URLs** – all pages point at `https://www.yashpackersgn.in/…`. Leave as is if the site will go live on that domain; change if not.

## Editing content

Every page is plain HTML. Open it in any editor, change the text, commit. GitHub Pages redeploys in about a minute.
The pages were generated by `build.py` (and the illustrations by `illus.py`), both included, so the header and footer are identical on every page. To change the header, footer or any product data in one place, edit `build.py` and run `python3 build.py` inside this folder; it rewrites all the HTML files.
